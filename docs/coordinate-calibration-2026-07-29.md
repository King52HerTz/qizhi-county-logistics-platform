## 数据来源与判定规则

1. 使用系统配置的高德 Web API 对每个名称执行正向地理编码。
2. 对返回坐标执行反向地理编码，要求省、市、区县与乡镇归属一致。
3. 检索同名村委会、服务中心、镇政府或物流园 POI；存在道路可达的精确 POI 时优先使用 POI，否则使用村级中心点。
4. 使用祁东县人民政府公布的农村寄递物流服务站名录确认现行行政村与乡镇归属。
5. 使用衡阳市物流规划和祁东县“十四五”规划确认县级仓配中心落在衡缘物流园。
6. 使用祁东县行政边界 GeoJSON 与 GeoPandas 对全部候选点执行面内检查，并使用 UTM 49N 计算纠偏距离。
