# AI 服务配置指南

## 1. 功能边界

AI 服务负责把调度指标和脱敏线路摘要整理成易懂的决策解释。车辆分配、容量、时间窗、冷链兼容和路线顺序仍由 OR-Tools 求解，未配置大模型也不影响核心调度功能。

## 2. 页面配置

1. 打开平台左下角“系统设置”。
2. 使用 `.env` 中的 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD` 登录。
3. 填写服务类型、API Base URL、服务商提供的模型 ID 和 API Key。
4. 点击“加密保存配置”。
5. 点击“测试连接”，确认右侧状态为“连接正常”。

OpenAI 兼容地址应能接收 `POST {Base URL}/chat/completions`。如果服务商文档给出的地址已包含 `/v1`，页面中保留该部分。

选择 OpenAI、DeepSeek 或通义千问时，页面会自动填入对应的推荐地址和模型。API Key、Base URL 与模型必须属于同一个服务平台；后端会拦截 DeepSeek 与 OpenAI 等明显混配。

## 3. 安全设计

- API Key 只在保存时从浏览器传到后端，之后页面仅显示掩码。
- 数据库字段保存 Fernet 密文，不保存明文。
- `AI_CONFIG_ENCRYPTION_KEY` 与数据库分离，通过运行环境注入。
- JWT 保存在当前标签页的 `sessionStorage`，关闭标签页后会话消失。
- 发给模型的内容不包含系统账号、数据库连接和 API Key。

## 4. 常见问题

- `首次配置必须填写 API Key`：当前数据库还没有配置记录，请填写有效密钥。
- `AI 服务未启用`：打开“启用 AI 解释”并保存。
- `401/403`：管理员会话已失效或当前账号不是管理员，请重新登录。
- 连接测试失败：核对 Base URL、模型 ID、密钥权限及服务器出网策略。
- `401 身份验证失败`：通常是 API Key 无效，或 API Key 与 Base URL 来自不同服务商、不同地域或不同计费方案。
