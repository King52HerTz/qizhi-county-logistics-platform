# 第十四阶段开发文档：空间数据校准与大地图运营工作台

## 1. 阶段目标

本阶段解决高德道路地图接入后的三个实际问题：

1. 早期业务场景中的近似坐标与真实道路、乡镇位置存在偏差。
2. “适配当前路线”错误地把县域边界和全部节点纳入视野，导致路线显示过小。
3. 调度页地图面积不足，放大后缺少快速回到完整路线的稳定操作。

在修复基础问题后，继续建设可长期使用的地图运营能力，包括道路级路线、坐标校准状态、路线/全局双视野和专注模式。

## 2. 设计原则

- 高德在线模式使用 GCJ-02 坐标；离线 GeoJSON 继续使用原始业务坐标，不对两种模式混用转换。
- 不对已经来自高德的数据执行二次坐标转换，避免产生新的偏移。
- 早期近似节点通过高德地理编码进行显示坐标校准，失败时安全回退到原坐标。
- 在线路线优先使用高德驾车路径，使路线沿真实道路绘制；服务失败时回退为节点直连线。
- “全部路线”和“当前路线”分别维护覆盖物集合，视野适配只计算目标集合。
- 地图成为调度页主工作区，指标卡片下移为横向运营栏。

## 3. 功能范围

### 3.1 坐标校准

- 高德地图加载后按“湖南省衡阳市祁东县 + 节点名称”进行地理编码。
- 对服务站、加工点、产业园、集散点等业务后缀进行标准化后再查询。
- 仅接受祁东县行政范围内的返回坐标。
- 配送中心等无法可靠匹配的自定义业务设施保留原始坐标。
- 地图状态栏显示已校准节点数量。
- 节点详情区显示当前地图坐标及校准状态。

### 3.2 道路级路线

- 使用高德驾车规划服务连接起点、途经点和终点。
- 路线沿实际道路绘制并显示方向。
- 路径规划失败时自动回退为节点直线，不影响调度页面使用。

### 3.3 独立视野管理

- “查看全部路线”：只适配当前筛选条件下的路线，不再包含行政边界。
- “查看当前路线”：只适配选中车辆的路线，并为右侧详情浮层预留边距。
- 切换车辆后自动完整展示该车辆路线。
- 缩放后可随时一键恢复完整路线。

### 3.4 大地图布局

- 调度地图改为整行主工作区，桌面端高度提升至约 700px。
- AI 评分、控制台和车辆任务调整为地图下方横向运营栏。
- 增加地图专注模式，可临时覆盖应用内容区。
- 手机端继续使用单列布局，并维持无横向滚动。

## 4. 技术方案

| 能力 | 技术 |
| --- | --- |
| 在线底图 | 高德地图 JavaScript API 2.0 |
| 地理编码 | `AMap.Geocoder` |
| 道路规划 | `AMap.Driving` |
| 在线坐标 | GCJ-02 |
| 离线地图 | ECharts + 祁东县 GeoJSON |
| 视野计算 | 高德覆盖物集合 `setFitView` |
| 安全访问 | 既有同源安全代理 |

## 5. 异常与降级

- 高德脚本不可用：切换离线县域地图。
- 地理编码无结果：使用场景原坐标，并标记为“原始坐标”。
- 驾车路径无结果：使用节点直连线。
- 路线为空：视野回退到业务节点；业务节点为空时回退到县域中心。
- 专注模式退出：支持按钮和 `Esc` 键。

## 6. 验收标准

1. 在线模式下乡镇节点与高德地名位置一致，未发生二次坐标偏移。
2. 路线沿真实道路展示，失败时仍能显示直连路线。
3. 点击“当前路线”后，完整路线处于可视区域且不被详情浮层遮挡。
4. 点击“全部路线”后，只按可见路线计算视野，不受县域边界影响。
5. 1600px 桌面视口中地图宽度显著增加，高度不低于 680px。
6. 专注模式可进入、退出，地图会随容器尺寸正确重绘。
7. 390px 手机视口无横向溢出。
8. 前端构建、后端测试和浏览器核心交互检查通过。
