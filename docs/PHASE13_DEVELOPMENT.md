# 第十三阶段开发文档：产品化表达与专业地图服务

## 1. 阶段目标

本阶段将平台从“项目展示型系统”进一步调整为可用于日常运营的县域物流决策产品，重点解决两类问题：

1. 清理系统可见区域中的赛事、答辩、演示等非生产化表达；
2. 将现有行政区轮廓图升级为可配置、可交互、可降级的专业调度地图。

本阶段完成后，用户看到的是“运营评估、能力验证、标准作业流程、成果归档”等企业化概念，不再暴露项目建设背景。

## 3. 地图总体架构

### 3.1 双引擎策略

平台支持两种地图运行模式：

- **离线运营地图**：系统默认能力，不依赖第三方 Key。显示县域边界、业务节点、路线、方向、图例和节点详情，确保断网时仍可工作。
- **高德道路地图**：可选增强能力。配置高德地图 Web JS Key 后，加载真实道路、河流、乡镇地名和地图控件，并叠加系统调度路线。

没有配置高德服务时，系统自动使用离线地图，不影响求解、审批和执行。

### 3.2 高德安全模式

根据高德 JavaScript API 2.0 的安全要求，新申请的 Web JS Key 需要配套安全密钥。平台采用以下边界：

- Web Key 与安全密钥由管理员在“系统设置 → 地图服务”中录入；
- 服务端加密保存，列表只返回掩码；
- 地图运行时只返回必须的 Web Key；
- 安全密钥由服务端代理附加，不直接返回给浏览器；
- 建议在高德控制台为 Web Key 配置可用域名白名单。

开发环境可以使用 `127.0.0.1` 或 `localhost` 测试，正式部署后应替换为实际域名。

## 4. 地图交互设计

### 4.1 地图主视图

- 大比例地图画布作为调度页面主视觉；
- 路线按车辆使用稳定颜色编码；
- 当前选中路线高亮，其他路线降低透明度；
- 停靠点显示顺序编号，配送中心使用独立图标；
- 事件模式显示故障点和受影响路线；
- 地图底部显示数据源、缩放级别和更新时间。

### 4.2 工具栏

- 路线筛选：全部、常温、冷链；
- 节点图层开关；
- 放大、缩小、复位、适配路线；
- 地图来源状态：离线地图 / 高德地图；
- 一键进入地图服务设置。

### 4.3 路线与节点详情

- 点击车辆任务或地图路线可切换当前路线；
- 点击节点显示名称、类型、到达时间、订单数和冷链属性；
- 路线详情展示车辆、站点数、距离、装载率和配送顺序；
- 移动端将右侧任务区转换为地图下方列表，避免横向滚动。

## 5. 数据模型

新增 `map_provider_configs`：

| 字段 | 说明 |
| --- | --- |
| `name` | 配置名称 |
| `provider` | 地图供应商，当前支持 `amap` |
| `encrypted_web_key` | 加密后的 Web JS Key |
| `encrypted_security_code` | 加密后的安全密钥 |
| `map_style` | 地图样式 |
| `enabled` | 是否作为默认地图 |
| `last_test_status` | 未测试、正常、失败 |
| `last_test_message` | 最近测试说明 |
| `created_by / updated_by` | 操作用户 |
| `created_at / updated_at` | 审计时间 |

同一时刻最多启用一个第三方地图配置。

## 6. API 设计

管理员配置接口：

- `GET /api/v1/map/configs`
- `POST /api/v1/map/configs`
- `PUT /api/v1/map/configs/{id}`
- `POST /api/v1/map/configs/{id}/activate`
- `POST /api/v1/map/configs/{id}/disable`
- `POST /api/v1/map/configs/{id}/test`

地图运行接口：

- `GET /api/v1/map/runtime`：管理员和调度员读取当前地图运行方式；
- `GET /api/v1/map/amap-service/{path}`：高德安全代理，不向前端暴露安全密钥。

## 8. 验收标准

1. 登录后可见页面和导出报告中不出现赛事、答辩、演示、比赛等字样；
2. 未配置高德 Key 时，离线地图完整可用；
3. 路线筛选、路线选择、节点选择、复位和缩放操作有效；
4. 管理员可以通过列表和抽屉新增、编辑、测试、启停地图连接；
5. 密钥保存后只显示掩码，接口和审计日志不返回明文安全密钥；
6. 高德配置启用后地图能够切换到真实道路底图，失败时自动回退；
7. 桌面端与移动端无横向溢出和主要内容遮挡；
8. 后端自动化测试、前端生产构建和 Docker 健康检查全部通过。

## 9. 后续准备

如需启用高德道路地图，请申请：

1. 高德开放平台“Web 端（JS API）”Key；
2. 与该 Key 配套的 `securityJsCode`；
3. 测试域名白名单（本机测试可配置 `localhost` 和 `127.0.0.1`）。

密钥应通过系统设置录入，不写入代码仓库或 Docker 镜像。
