祁智运县域物流智能调度平台
============================

一、使用者需要做什么

1. 电脑首次使用前，只安装一次 Docker Desktop：
   https://www.docker.com/products/docker-desktop/

2. 安装过程保持默认选项，安装完成后不需要配置 Python、Node.js、数据库或环境变量。

3. 双击“启动祁智运平台.bat”。

4. 等待窗口显示“全部服务已经就绪”，浏览器会自动打开系统。

三、日常操作

启动系统：双击“启动祁智运平台.bat”

停止系统：双击“停止祁智运平台.bat”

检查故障：双击“检查平台状态.bat”，把窗口截图发给维护人员

恢复演示：双击“一键恢复标准演示数据.bat”，输入 RESET 后等待自动完成
恢复后“动态事件”的红色数字会重新出现，这是标准流程的初始待处置状态，并非恢复失败。

操作引导：首次登录会自动出现 5 步操作引导。完成或关闭后，可点击页面右上角“操作引导”重新打开。
引导只负责定位页面与按钮，不会自动提交审批、重新求解或下发驾驶员任务。


四、注意事项

1. 第一次启动需要联网下载基础镜像，通常需要数分钟。
2. 第一次完成以后，再次启动会明显加快。
3. 关闭浏览器不会停止系统；不再使用时请双击停止脚本。
4. 停止脚本不会删除订单、地图配置或 AI 配置。
5. 不要删除项目文件夹中的 docker-compose.yml、backend、frontend、deploy 和 scripts。
6. 系统地址：http://127.0.0.1
7. 恢复演示数据前会自动备份数据库，AI Key 和高德地图配置不会被删除。


五、无需操作的内容

使用者不需要：

- 安装 Python
- 安装 Node.js
- 安装 PostgreSQL
- 执行命令行
- 修改 .env
- 手动启动前端或后端
